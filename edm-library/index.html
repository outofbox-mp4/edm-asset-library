01 · industry baseline

EDM 的五项金标准

不论活动、生命周期还是产品通知，先满足这些基础，再谈视觉或自动化。

◎01

受众相关性

按生命周期、使用行为和购买意图分层，而非对全量名单使用同一信息。

→02

单一目标

每封邮件只推动一个主行动：激活、升级、续费、回流或了解活动。

+03

价值先于优惠

先说明用户能获得什么，再说明为什么现在行动更划算。

□04

交付与可读性

主题行、Preheader、层级、移动端、Gmail 和 Outlook 都是体验的一部分。

↗05

可衡量闭环

使用点击、转化、退订、送达和后续行为持续反哺下一轮分层与内容。

02 · quality path

一次好的邮件营销，应该这样完成

把“创作”改造成可执行、可审核、可复盘的工作流。

STEP 01

定义策略

明确人群、业务目标、发送时机、主 CTA 与成功指标。

STEP 02

选择资产

优先复用已验证模板和组件，再由 Agent 生成分层版本。

STEP 03

质量检查

检查品牌、变量、URL、UTM、邮件客户端与移动端表现。

STEP 04

复盘沉淀

记录分层、表现和结论，将有效做法升级为可复用资产。

04 · agent evaluation

Agent 时代的评判标准

不以“生成速度”作为唯一标准，而是看每次自动化是否让营销工作更准确、更稳定、更可复用。

STANDARD 01

策略匹配度

输出是否准确匹配目标人群、业务目标、优惠边界与单一主 CTA。

STANDARD 02

首轮质量通过率

品牌、分层文案、变量、URL、UTM、移动端和客户端检查能否一次通过。

STANDARD 03

资产复用率

是否优先使用已验证模板与组件，而非每次从零生成新的不确定版本。

STANDARD 04

真实参与与业务增量

结合过滤机器行为后的有效点击、落地页互动与后续转化；打开率仅作辅助信号。
