# Growth Asset Library

Personal growth asset library for advertising and email marketing work. GitHub stores the source files; the published site provides browsable previews and context.

## Start here

Open `index.html` for the shared growth desktop. Advertising and EDM are two apps in the same interface. `edm-library/index.html` opens that desktop with the EDM app selected. The previous EDM overview remains at `edm-library/overview-classic.html`.

The desktop interaction and pixel art are adapted from the [Cats with Jobs Webflow Clonable](https://cats-with-jobs.webflow.io/) by KC Kat Creative. Credits also appear inside the desktop.

## Contents

- `edm-library/`: asset-site pages, reusable components, standards, and central metadata.
- `outputs/black-friday-early-bird/`: approved Black Friday Early Bird email HTML and copy files.
- `outputs/black-friday-main-phase/`: approved Black Friday main-phase email HTML and copy files.

## Maintenance

See [`edm-library/README.md`](edm-library/README.md) for the template entry schema and quality gates.

Only send-ready templates should be recorded as `已验证`. Do not commit recipient data, authentication files, report exports, or local runtime files.
