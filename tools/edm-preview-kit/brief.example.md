# 活动背景示例

这是一个**示范输入**，展示用户可以怎样用自然语言提需求；不代表真实活动信息。

我们要推广 Octoparse 的网站数据采集能力。目标是让新用户开始第一次数据采集，也让现有付费用户考虑更稳定的周期性采集。活动目前处于预热期，尚未公布优惠价格和结束时间，因此邮件里不要写具体折扣或倒计时。

请做两个分层：

- **新注册和免费用户：**突出“从网站 URL 和目标开始，找到合适的采集方式”，主 CTA 指向产品介绍。
- **在期付费用户：**突出周期性任务和容量选择，主 CTA 指向套餐介绍。

请参考 Colorlib 或已有品牌邮件，选择一套统一、清爽的整体风格，分别写文案和 HTML，再生成可切换的桌面 / 手机预览。每封邮件都要有 Subject、Preview text 和单独的 HTML。落地页可暂用 `https://www.octoparse.com/` 作为示范链接，并在交付时提示替换。
